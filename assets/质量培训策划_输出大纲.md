# 质量培训策划方案 · 输出大纲

> 本大纲为 `quality-training-planner` 技能生成培训方案的骨架。定位与范围确认后，Agent 先展示此大纲供确认，再生成正式正文（MD + HTML 双版本）。

---

## 报告章节结构

1. **封面与元信息**
   - 培训项目名称 / 用途场景 / 培训对象 / 培训主题 / 培训时长 / 培训目标 / 特殊要求

2. **一、培训背景与目的**
   - 为何办此次培训、期望达成的组织/岗位效果

3. **二、培训目标（知识/技能/态度三层）**
   - 知识目标：理解/掌握的概念、原理、标准
   - 技能目标：能操作的工具、能解决的问题
   - 态度目标：应树立的质量意识与行为习惯

4. **三、课程大纲**
   - 按天/按模块组织：模块名 · 内容要点 · 教学方法 · 学时（精确到 0.5h）
   - 附「课程大纲学时时间轴」图（模块条形堆叠，直观看学时分配）
   - 实操占比按用户要求（默认 ≥30%）

5. **四、教学方法设计**
   - 各模块教学法选择依据（讲授/案例/讨论/实操/游戏化/混合）

6. **五、考核方式**
   - 笔试（题型·时长） / 实操（内容） / 项目报告（要求） / 评分标准

7. **六、讲师要求**
   - 经验年限 / 专业能力 / 培训经验

8. **七、资源准备清单**
   - 教具设备 / 资料准备 / 软件工具 / 场地要求

9. **八、效果评估建议（柯氏四级）**
   - 反应层 / 学习层 / 行为层 / 结果层（四层卡）

10. **九、待企业补充项**
    - 汇总所有「待企业补充」占位（内部案例、标准编号、专属参数等）

---

## 生成产物

- `质量培训策划_方案.html`（精美网页版：学时时间轴 + 柯氏四层卡）
