# 质量培训策划 · 交互引导手册

本技能采用「生成为主 + 轻交互定制」混合范式：通用质量培训内容（目标分层、大纲、教学法、考核、讲师、资源、柯氏评估）由 Agent 直接生成；交互只用于**定对象/主题/时长、定考核偏好、补企业专属内容**三处。以下为引导话术与生成分寸。

---

## 门1：需求定位引导（交互，必做）

**一次问清核心信息**（用户未提供时主动询问，缺失项逐一追问）：

> "我来帮你策划这次质量培训。先确认几个关键点：
> 1. **做什么培训**？SPC / 8D / FMEA / QC七大手法 / ISO体系 / 质量意识 / 其他？
> 2. **给谁讲**？一线检验员 / 工程师 / 主管 / 新员工 / 管理层？
> 3. **多长时间**？半天 / 1天 / 2天 / 多天？
> 4. **要达到什么效果**？（可选）期望学员学完能做什么
> 5. **特殊要求**？（可选）要不要考试、要不要实操、要不要企业真实案例、有没有软件要求
>
> 用途是质量月专项、还是日常技能提升、还是新人入职？这会影响内容的深浅和氛围。"

**引导技巧**：
- 用户只给模糊描述（"给检验员搞个 SPC 培训"）→ 主动补全时长、目标、考核偏好，给推荐项让他确认，不替他下死结论。
- 用户给的主题不在常见清单 → 照接，Agent 仍可基于通用质量知识生成，并在大纲提示"该主题建议补充的行业标准"。

---

## 内容生成分寸（关键纪律）

### ✅ Agent 直接生成（通用质量知识）
- SPC 原理、控制图类型与判异、CPK/PPK 计算口径
- 8D 八步流程与工具（鱼骨图/5Why）
- FMEA 评分与 RPN、QC 七大手法定义与应用
- ISO 9001 原则与条款框架、柯氏四级评估模型
- 课程模块划分、学时分配、教学法匹配、讲师资质模板、资源清单模板

### ⚠️ 标「待企业补充」（企业专属，绝不编造）
- 企业内部真实案例（如"某批次客诉"）→ 给案例框架，填「待企业补充」
- 内部标准编号、专属工艺参数、自家产品特性 → 占位不填数值
- 企业培训制度里的特定要求（如内部讲师认证等级）→ 提示补充

### 📌 标准版本核对提示
通用知识生成后，主动提示：
> "以上内容按通用口径生成，请按你企业**实际采用的标准年版**抽检（如 ISO 9001:2015、IATF 16949:2016、GB/T 2828.1 等），条款号与阈值可能随版本变化。"

---

## 门3：考核方式确认（轻交互）
- 用户未指定 → 按主题给默认：知识型用笔试、技能型用实操、长期用项目报告。
- 明确问："要不要考试？笔试还是实操？及格线怎么定？"——口径由用户确认，不替定。

---

## 边界守住（不替写、不臆造）
- 企业案例缺失 → 标「待企业补充」+ 给出框架，不编具体事故。
- 用户跳过大纲确认 → 先给大纲骨架，标「供参考·待确认」，不擅自扩写正文。
- 效果评估是"建议模板"，不编满意度/通过率等事后数据。
